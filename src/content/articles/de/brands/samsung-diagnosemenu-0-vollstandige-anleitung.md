Samsung dokumentiert `*#0*#` offiziell als Weg zum Hardwaretest auf geeigneten Galaxy-Geräten. [Samsungs Supportseite](https://www.samsung.com/ch/support/mobile-devices/wie-kann-ich-einzelne-hard-oder-software-funktionen-testen/) verbindet den Code direkt mit Tests unter anderem für Displayfarben, Hörer, Vibration, Sensoren, Touchscreen, Lautsprecher, Tasten, Frontkamera, Schwarzbild und LED, sofern vorhanden.

Der Code ist nicht auf jedem Galaxy garantiert. Modell, Region, Provider-Firmware, Unternehmensrichtlinie, Sicherheitseinstellungen, Samsung-Phone-Version und One-UI-Build können den Zugriff ändern oder blockieren.

## Den dokumentierten Code ausprobieren

Öffne Samsungs eigene Telefon-App und gib `*#0*#` auf dem Tastenfeld ein. Drücke nicht auf Anrufen. Öffnet sich das Testraster, wähle nur einen nicht-destruktiven Hardwaretest und beobachte die Anzeige.

Das genaue Raster kann von Samsungs Beispiel abweichen. Eine fehlende Schaltfläche belegt keinen Defekt; ein bestandener Test belegt nur, dass die Funktion in diesem Moment reagiert hat.

## Wenn sich der Code nicht öffnet

Deaktiviere keine Sicherheitskontrollen, nur um ein verstecktes Menü zu erzwingen. Nutze stattdessen die [Diagnose in Samsung Members](https://www.samsung.com/us/support/answer/ANS10003443/). Tests und Menüpfade unterscheiden sich nach Gerät, Land und Appversion, dies ist jedoch Samsungs normaler unterstützter Diagnoseweg.

Dieser Artikel empfiehlt keine undokumentierten Codelisten. Codes für Firmware, Funkkalibrierung, Zurücksetzen, Bereitstellung oder Serviceprogrammierung können den Gerätezustand ändern und sollten nicht aus einer ungeprüften Liste eingegeben werden.

## Tests auswerten

Vollfarb- und Schwarzbildtests können sichtbare Pixel- oder Gleichmäßigkeitsprobleme zeigen, zertifizieren aber nicht das gesamte Display. Touch-Tests können Bereiche zeigen, die während des Tests nicht reagieren. Kacheln für Hörer, Lautsprecher, Vibration, Sensor, Taste und Kamera zeigen eine momentane Reaktion, nicht die langfristige Zuverlässigkeit.

Schlägt ein Test fehl, starte das Telefon neu, entferne störendes Zubehör, installiere unterstützte Updates und wiederhole den Test einmal. Ein anhaltender Fehler sollte vom Samsung-Support oder einem autorisierten Betrieb geprüft werden.

## Verfügbarkeit von One UI 9

[Samsungs aktuelle One-UI-9-Seite](https://www.samsung.com/us/apps/one-ui/) sagt, dass das offizielle One UI 9 zuerst auf Galaxy Z Fold8 Ultra, Galaxy Z Fold8 und Galaxy Z Flip8 ausgerollt wurde und voraussichtlich schrittweise auf weiteren Galaxy-Geräten erscheint. Die Verfügbarkeit hängt von Modell, Land oder Region, Anbieter, Firmware und Build ab.

Diese Rollout-Angabe garantiert `*#0*#` nicht auf einem bestimmten Gerät. Nutze die offizielle Codeseite für den Umfang des Codes und Samsung Members, wenn der Tastenfeldweg fehlt.
